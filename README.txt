SKYNEST WEBSITE — FIRST TWO PAGES

FILES
- index.html       Homepage
- about.html       About Us page
- css/style.css    Shared styling for both pages
- js/script.js     Shared mobile navigation behaviour
- images/          Put your photos in this folder

HOW TO OPEN
1. Extract the ZIP folder.
2. Keep the folder structure exactly as it is.
3. Open index.html in a browser.
4. Use the Home and About us links in the navigation to move between the two pages.

IMAGE PLACEMENT GUIDE
Add your own photos to the images folder using these exact filenames:

Homepage:
- home-hero.jpg  Main large hero photo on the left. Use a wide, high-quality photo of a bright co-living lounge or attractive shared interior. Suggested ratio: 4:5 or portrait.
- home-card-1.jpg  Furnished private bedroom. Suggested ratio: 4:3 landscape.
- home-card-2.jpg  Co-working space. Suggested ratio: 4:3 landscape.
- home-card-3.jpg  Shared kitchen/dining area. Suggested ratio: 4:3 landscape.
- home-card-4.jpg  Rooftop garden, gym or relaxation space. Suggested ratio: 4:3 landscape.

About Us:
- about-community.jpg  Residents/social community or people enjoying a shared lounge. Suggested ratio: 4:3 landscape.
- about-spaces.jpg  Stylish shared interior, co-working lounge or communal area. Suggested ratio: 4:3 landscape.

IMPORTANT
- Use JPG images and keep the exact filenames above, or update the matching src value in the HTML.
- The image boxes show a labelled placeholder if a photo has not been added yet.
- Google Fonts are loaded from the internet. If offline, the browser will use similar fallback fonts.
- The navigation links for Facilities, Packages, FAQ and Contact are included for the planned full website, but those pages have not been created yet. They will work once their HTML files are added.
- This is a beginner-friendly HTML/CSS/JavaScript website; no framework or installation is needed.
